Projeto de Robótica · Arduino

Alarme inteligente contra ladrão

Um circuito feito com Arduino e sensor de luz (LDR): quando alguém entra no escuro ou tampa o sensor, o buzzer toca e o LED pisca.

Testar o simuladorVer como funciona

Como funciona

Quatro etapas simples, do sensor até o alerta.

  1. Ler a luz. O Arduino lê o sensor LDR no pino A0 o tempo todo e mostra o valor no monitor serial.
  2. Detectar a sombra. Se a leitura cair abaixo de 400, o sistema entende que alguém bloqueou a luz ou apagou a iluminação.
  3. Disparar o alarme. O buzzer toca a 1000 Hz no pino 11 e o LED do pino 12 pisca a cada 200 ms.
  4. Voltar ao normal. Quando a luz volta, o LED e o buzzer desligam sozinhos.

Código do Arduino

Código real do projeto: o alarme dispara quando o LDR detecta sombra.

// ====================================================
// Circuito Antifurto: LDR + Buzzer + LED Piscando
// ====================================================
const int pinLDR = A0;
const int pinLED = 12;
const int pinBuzzer = 11;
const int LIMIAR_SOMBRA = 400;

void setup() {
  pinMode(pinLED, OUTPUT);
  pinMode(pinBuzzer, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Leitura do sensor LDR
  int leituraLDR = analogRead(pinLDR);
  Serial.print("Leitura LDR: ");
  Serial.println(leituraLDR);

  // Verifica a luminosidade
  if (leituraLDR < LIMIAR_SOMBRA) {
    // Ativa o alarme
    digitalWrite(pinLED, HIGH);
    tone(pinBuzzer, 1000);
    delay(200);

    // Pisca o LED e interrompe o buzzer
    digitalWrite(pinLED, LOW);
    noTone(pinBuzzer);
    delay(200);
  } else {
    // Mantém o sistema desligado
    digitalWrite(pinLED, LOW);
    noTone(pinBuzzer);
    delay(100);
  }
}
