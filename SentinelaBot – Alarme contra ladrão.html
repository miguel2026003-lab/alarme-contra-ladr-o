Projeto de Robótica · Arduino

Alarme inteligente contra ladrão

Um sistema de segurança feito com sensores e Arduino que detecta movimento, dispara a sirene e avisa o dono da casa na hora.

Testar o simuladorVer como funciona

Como funciona

Quatro etapas simples, do sensor até o alerta.

  1. Armar o sistema. O dono digita a senha no teclado ou aperta o botão e o alarme entra em vigilância.
  2. Detectar a invasão. O sensor PIR percebe o calor do corpo em movimento e o sensor ultrassônico mede a distância até a porta.
  3. Disparar o alarme. O Arduino liga a sirene (buzzer) e o LED vermelho piscando.
  4. Avisar o dono. Com um módulo Wi-Fi (ESP8266 ou ESP32), o projeto manda uma notificação para o celular.

Código do Arduino

Exemplo básico para começar. Ajuste os pinos conforme sua montagem.

const int PIR = 2;
const int BUZZER = 8;
const int LED = 9;
const int BOTAO = 4;
bool armado = false;

void setup() {
  pinMode(PIR, INPUT);
  pinMode(BUZZER, OUTPUT);
  pinMode(LED, OUTPUT);
  pinMode(BOTAO, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(BOTAO) == LOW) {
    armado = !armado;
    delay(500);
  }
  if (armado && digitalRead(PIR) == HIGH) {
    digitalWrite(BUZZER, HIGH);
    digitalWrite(LED, HIGH);
    delay(200);
    digitalWrite(LED, LOW);
    delay(200);
  } else {
    digitalWrite(BUZZER, LOW);
    digitalWrite(LED, LOW);
  }
}
